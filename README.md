# 🕯️ Scents & Scripts — E-Commerce Homepage

A mobile-responsive static e-commerce homepage built for the Zuitt Coding Bootcamp App Building module. **Scents & Scripts** is an artisanal boutique concept blending oil-based perfumery, hand-poured soy scented candles, and heirloom stationery (journaling pens and botanical sealing wax sets).

## 🚀 Live Demo
You can view the live deployed application here:  
👉 [https://leighasilang.github.io/s83-MTE/]

---

## 🛠️ Built With & Technologies Used
* **HTML5 & CSS3**: Semantic markup and custom styling.
* **Bootstrap 5.0.2**: Grid system, responsive utility classes, navbar collapse, and interactive carousel components.
* **Google Fonts**: *Cormorant Garamond* (serif headings) and *Plus Jakarta Sans* (body text).
* **Bootstrap Icons**: UI vector iconography.

---

## 🎨 Design & Color Palette
The site features a soft, dreamy visual aesthetic inspired by the following custom color palette:
* **Cloud White (`#F7F9FC`)**: Clean background and containers.
* **Powder Blue (`#BFD7EA`)**: Soft borders, cards, and footer background.
* **Sky Blue (`#82B8D9`)**: Brand accents, pricing tags, and button details.
* **Lavender (`#B9A7D8`)**: Badges and section dividers.
* **Navy (`#263B5E`)**: Primary typography and high-contrast call-to-action buttons.

---

## 💻 Page Sections & Features
1. **Navbar**: Fixed-top responsive navigation bar featuring brand identity, center links (*Home, Shop, About, Contact*), search bar, interactive cart counter badge, and login action.
2. **Hero Section (`id="hero"`)**: High-impact introduction banner showcasing the boutique's core offering with quick-action CTA buttons.
3. **Carousel Highlights**: Interactive Bootstrap slider highlighting collection features, seasonal oil blends, and bundle promotions.
4. **Featured Products Heading & Grid**: A fully responsive 4-column card grid highlighting artisanal oil perfumes, scented candles, journaling pens, and wax seal kits with hover animations.
5. **Multi-Column Footer**: Organized footer containing site directory links, apothecary categories, customer support links, and copyright notice.
